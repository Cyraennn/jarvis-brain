Buraya "armor.glb" adinda bir model koyarsan (sonra: cd web3d && npm run build),
prosedurel zirh yerine o yuklenir. Model ~1.9 birim boya olceklenir, ayaklari zemine
oturtulur ve ayni olusma (dissolve) efekti kendi malzemelerine uygulanir.
Lisansini kendin kontrol et: Iron Man tasarimi Marvel'e aittir.
